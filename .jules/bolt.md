## 2026-06-15 - Python String Truncation with split() vs maxsplit
**Learning:** Performing standard `.split()` on very large strings (e.g., 10MB+) without parameters allocates memory and creates list objects for every word in the entire string. Calling `.split()` multiple times on the same large string multiplies this CPU and memory overhead. Using python's native `.split(None, maxsplit)` with a specific limit avoids splitting the rest of the string entirely, avoiding massive memory allocations and resulting in over an 80x speedup (e.g., reducing string chunking from ~0.44s to ~0.005s on a 10MB file).
**Action:** Always prefer `.split(None, maxsplit)` when performing truncation or size checks on text files or long strings where only a prefix or a subset of the words are needed.
